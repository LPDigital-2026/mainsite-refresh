How to use it
  1. Upload the latest theme zip first (Appearance → Themes → Add New → Upload, then Replace), because the styles for these pages live in the theme.
  2. In WP Admin open the page, switch to the Code Editor (top-right menu → Code editor).
  3. Select all, delete, paste, then press Update.
