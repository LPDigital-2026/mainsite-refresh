Lily Paw Digital — All Page Content

Every page's block content in one place. Open a page below and press its Copy button.

You normally don't need this file. The lilypawdigital theme sets the pages up by itself: it creates any that are missing and updates any you haven't edited, every time the theme changes. Pages you have edited are left alone; Appearance → Page Setup lists them and can replace one on request. This file is only for pasting by hand.

How to use it
  1. Upload the lilypawdigital theme zip first (Appearance → Themes → Add New → Upload) and activate it, because the styles for these pages live in the theme.
  2. In WP Admin open the page, switch to the Code Editor (top-right menu → Code editor).
  3. Select all, delete, paste, then press Update.
